# Как быстро меняется вкус в ленте коротких видео?

**Что лучше предсказывает досмотр видео: давние вкусы пользователя, его последние просмотры или качество самого видео?**

Данные: [VK-LSVD](https://huggingface.co/datasets/deepvk/VK-LSVD), сабсэмпл `up0.001_ip0.001` (10 тыс. активных пользователей, 19.6 тыс. популярных видео, 48 млн показов за 26 недель).

## Выводы

1. **Личный вкус убывает вдвое примерно за 1300 показов** (около двух месяцев для среднего пользователя выборки), но устойчивое ядро сохраняется месяцами.
2. **Качество видео предсказывает досмотр сильнее всего:** NDCG@10 0.521 против 0.401 у вкуса пользователя и 0.334 у случайного порядка.
3. **Вкус даёт значимый прирост поверх качества видео:** +0.0054 (95% ДИ от 0.0037 до 0.0070).
4. **Короткая память не помогает.** Лучшая память около 1000 показов. Отдельный краткосрочный вектор не даёт значимого прироста (+0.0006, ДИ от −0.0004 до 0.0017).
5. **Сырые эмбеддинги дают профиль хуже случайного** (0.327) из-за общей компоненты. Я исправила это вычитанием среднего эмбеддинга.

## Методика

- **Позитив:** лайк, репост, закладка или просмотр от 90% длины. **Скип:** дизлайк или просмотр меньше 20%.
- `drift.py` строит вектор вкуса по блокам из 50 показов и сравнивает его с вектором того же пользователя через N показов и с вектором случайного другого пользователя.
- `predict.py` проигрывает последнюю неделю как онлайн-ленту: показы режутся на чанки по 20, модель ранжирует чанк по прошлым данным и только потом видит реакции. Параметры я подобрала на неделе 24, а проверила на неделе 25. Доверительные интервалы получены парным бутстрэпом по пользователям.

| Модель | NDCG@10 |
|---|---:|
| Случайный порядок | 0.334 |
| Давние вкусы | 0.401 |
| Последние просмотры | 0.399 |
| Качество видео | 0.521 |
| Качество видео + давние вкусы | 0.526 |
| Качество видео + давние вкусы + последние просмотры | 0.527 |

Остальные таблицы лежат в `results/`.

## Запуск

```bash
pip install -r requirements.txt
python drift.py
python predict.py
```

Первый запуск скачивает около 2.8 ГБ в `VK-LSVD/` (папку можно поменять через `VK_LSVD_ROOT`). Каждый скрипт работает меньше минуты и требует около 4 ГБ памяти.
